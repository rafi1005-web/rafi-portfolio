# Portofolio Magang Mobile Developer

File HTML portofolio magang yang sudah diperbaiki dan siap digunakan.

## Cara Menggunakan:
1. Ekstrak file ZIP ini.
2. Buka `index.html` menggunakan browser favorit Anda (Chrome, Firefox, Edge, dll.).
3. Anda dapat mengedit isi `index.html` menggunakan text editor seperti VS Code untuk mengganti nama, foto, atau tautan proyek Anda.
